Quiz: Complexity Basics

Essay Question:
Describe the `time` complexity of:
A) searching a number in an unsorted list
B) searching a number in a sorted list using binary search
C) sorting a list using bubble sort

Provide a brief explanation for each case (for example, justify why the complexity is O(n)).

Student Answer:
A) In an unsorted list we check all elements to check if the searched number is equal to each element.  So is n checks, n operations, so O(n).
B) In sorted list we check one element in a certain index ( middle index) and the iteration 2 checks again one element and discard half of what left. Overall i will check base 2 logn times and complexity is O(logn).
C) In bubble sort we in first iteration check all items once so n times, then in second iteration n-1 times, then n-2 times etc but in the limit of infinite the -1 , -2 , -3 etc are insignificant so we do n checks for each of n iterations so O(n^2) times.
